# 更新记录

## 0.1.1 · 2026-11-23

- 引入随包分发的 Noto Sans SC / Inter 可变字体，使用连续字重，避免系统字体的粗细跳变。主要正文 15–16px，标签与辅助文字以 12–14px 为主，大窗口增加一级字号。
- 强化正文与标签的对比度，保留浅蓝、苔绿与淡紫的视觉层次。
- 二级弹层加入进入/退出动画；关闭时先隔离交互，再移除节点并恢复触发按钮的焦点。
- 设置分类支持淡出/进入与上下方向键、Home、End 导航。弹层打开时，主窗口快捷键不再改变背景会话。
- 侧栏平滑收展，收藏页柔和切换，点子细节通过网格高度过渡展开，收起内容退出键盘与辅助技术访问。
- 聊天框支持空白区域点击聚焦、内容自动增高、明确的焦点轮廓；按钮、卡片和收藏有轻量反馈。
- 指针局部光感不替换系统指针，不拦截控件与文本选择；触屏和减少动态效果模式不跟随指针。
- 桌面验证新增字体加载、1800px 与 960px 窗口、输入区焦点与尺寸、弹层焦点生命周期、键盘分类、减少动态效果和细节展开检查。
