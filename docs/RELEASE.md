Divergence 首个公开版本：为开放式问题提供多个有创造力、可落地的方向。

- 三个独立视角发散、跨界重组；快速模式与引导问答。
- 点子卡片、收藏、继续分支与 Markdown 导出。
- 多套网站 HTML demo 的隔离预览与导出。
- 自带 Key 的兼容模型接入，API Key 系统加密，本机会话保存。
- 标准 SKILL.md 与 MCP stdio / Streamable HTTP 工具插件。
- 无账号、无遥测；只从 GitHub Releases 手动更新。

Windows x64：下载 `.exe` 一键安装，或 `.zip` 解压后运行 Divergence.exe。无需 Node.js。

首次运行使用明确标注的固定示例。真实生成请在设置中关闭体验模式并配置模型。实时检索需要接入自己的搜索 MCP。首版未购买代码签名证书。更多使用方法、研究出处和当前功能边界见仓库 README。
