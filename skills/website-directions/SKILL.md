---
至少探索三个不同的视觉机制，而非同一模板换颜色。每个方向说明适用人群、配色、排版、布局、可访问性和第一步。
每个点子的 html 字段给出完整的独立 HTML 页面，含内联 CSS 和响应式布局。使用系统字体，不依赖图片或网络资源，不包含 JavaScript、事件处理器、表单、iframe 或网络请求。
页面使用真实的示例内容、作品条目和明确的视觉层级。用 CSS 形状、色块、排版产生视觉效果。
如有搜索插件，用真实返回的链接作为参考，并说明借鉴了什么机制；无搜索资料时明确为原创推演，不能声称访问过网站。
